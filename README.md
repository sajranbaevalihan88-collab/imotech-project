## О проекте и решаемой реальной проблеме

**ImoTech (ЫмТили)** — это прикладная интеллектуальная платформа компьютерного зрения (`MediaPipe Hands 21-Point`) для перевода кыргызской и русской дактильной азбуки, цифр и слов КЖЯ с трёхъязычным интерфейсом (`RU / KG / EN`).

- **Реальная проблема:** На весь южный регион Кыргызстана работает менее 15 дипломированных сурдопереводчиков — глухой человек не может без посредника объяснить симптомы врачу, назвать номер талона или оформить паспорт в ЦОНе. Зарубежные системы обучены только на американском амслене (ASL) и не распознают кыргызскую и русскую дактильную азбуку (`А–Я`, включая специфические буквы `Ө`, `Ү`, `Ң`), пальцевый счёт цифр (`0–9`) и лексику КЖЯ.
- **Статистика и актуальность:** В Кыргызстане проживает более **32 000 граждан** с нарушениями слуха и речи, из них свыше **9 000** — в Ошской, Джалал-Абадской и Баткенской областях.
- **Четыре главных модуля платформы:**
  1. **🖐️ Живой сканер жестов ➔ Буквы и Цифры:** Считывает 21 ключевую точку кисти с веб-камеры и изгиб каждого из 5 пальцев (`[Большой, Указательный, Средний, Безымянный, Мизинец]`), переводя жест в **цифры (`0–9`)**, **буквы дактиля (`А–Я`, `Ө`, `Ү`, `Ң`)** и фразы с автоматической сборкой слов и чисел. EMA-сглаживание ключевых точек + голосование большинством по кадрам убирают дрожание и ложные срабатывания.
  2. **🎬 Покадровая обработка видеофайлов (`.MP4 / .WEBM / .MOV`):** Реальная серверная обработка (`OpenCV` выборка кадров + `MediaPipe Hands` на пикселях) и браузерный MediaPipe-скан при воспроизведении; таймлайн распознанных букв/цифр, субтитры `.SRT` и `.TXT`.
  3. **🖼️ Обработка фотографий (`.JPG / .PNG / .WEBP`):** Реальная серверная обработка загруженного снимка (пиксели ➔ `MediaPipe HandLandmarker`), браузерный 21-точечный захват кисти, перевод жеста в букву/цифру/слово КЖЯ и отчёт `.TXT` (RU / KG / EN).
  4. **▶️ Перевод видео по ссылке из YouTube:** **Реальная серверная обработка** — `yt-dlp` скачивает видео (≤480p), `OpenCV` выбирает кадры, `MediaPipe Hands` распознаёт жесты по настоящим пикселям; встроенный плеер + таймлайн на `RU / KG / EN`. При блокировке YouTube (bot-check) автоматический резерв — живой захват экрана плеера через `MediaPipe Screen Capture`.

## Реализованный технологический стек

- **Backend:** Python 3.11+, FastAPI (`0.115.6`), Pydantic v2 (`2.10.4`), Uvicorn (`0.34.0`), встроенная СУБД **SQLite 3** (WAL-режим, полная автономность без внешних БД-серверов).
- **Real CV-пайплайн (сервер):** `yt-dlp` (скачивание YouTube ≤480p) + `OpenCV 5` (выборка кадров, декодирование фото/видео) + `MediaPipe HandLandmarker 21-Point` (новый Tasks API) — все символы распознаются по реальным пикселям медиафайлов.
- **CV-нейросеть (браузер):** **MediaPipe Hands 21-Point** (Google) — веб-камера, видеофайлы, фотографии и захват экрана YouTube; геометрический классификатор 21 точки ➔ цифры / дактиль / слова + EMA-сглаживание и голосование большинством.
- **Frontend:** React 18, тёмная/светлая темы через CSS-переменные, трёхъязычный словарь (`RU / KG / EN`), экспорт субтитров `.SRT` и отчётов `.TXT`.
- **Автотесты:** `SandboxTestClient` (прямой прогон через ASGI-стек FastAPI `app(scope, receive, send)`) + `pytest==8.3.4`.

## Что переводит система

| Тип | Расшифровка |
|---|---|
| **Цифры `0–9`** | Пальцевый счёт: кулак `0`, указательный `1`, V-жест `2`, … кольцо ОК `9` |
| **Буквы дактиля `А–Я`** | Вся русская дактильная азбука |
| **Кыргызские буквы `Ө, Ү, Ң`** | Специфические буквы кыргызского дактиля, которых нет в ASL |
| **Слова КЖЯ** | САЛАМ, РАХМАТ, ПАСПОРТ, ЖАРДАМ, ДАРЫГЕР, СПРАВКА, ОШГУ, МЕН |

Распознанные символы автоматически собираются в слова и числа, которые можно скопировать или скачать (`.SRT` / `.TXT`).

## Быстрый запуск (Windows — в 2 клика)

1. Дважды кликните **`start-backend.bat`** — запустится FastAPI сервер на `http://localhost:8010` (Swagger: `http://localhost:8010/docs`).
2. Дважды кликните **`start-frontend.bat`** — соберётся и откроется веб-приложение на `http://localhost:3010`.

### Проверка автотестов (Pytest)

```bash
cd backend
python -m pytest tests/ -v
```
